Calculator V1
-
Features:
- 
+ Addition;
+ Subtraction;
+ Division;
+ Multiplication;
+ Interactive start menu;
+ Double number support;
+ Input using Scanner.hasNextDouble();
+ Ability to return to the main menu;
+ Exit option;

Technologies
-
+ Java 27, Scanner

Input format
-
Calculator uses the US number format
Use a dot (.) as the double separator
Example: 31.15
